Getting started

Ready when you are.

Choose your platform, install the CLI, and open your dashboard.

macOS & Linux

macOS Apple silicon or Linux x86-64

curl -fsSL https://raw.githubusercontent.com/guna81/llm-cli-gateway/main/install.sh | sh

Windows

Windows x86-64 · PowerShell

irm https://raw.githubusercontent.com/guna81/llm-cli-gateway/main/install.ps1 | iex

Start AgentBridge

Open a new terminal if needed, then run:

agentbridge start --personal
agentbridge dashboard

The dashboard opens signed in. Install and sign in to your chosen agent CLIs separately. Create an API key in the dashboard and point compatible clients to http://127.0.0.1:43187/v1.

Installers require a published release; binaries are currently unsigned. Linux packages target glibc-based systems such as Ubuntu 22.04 or newer, and the tray requires a supported X11 desktop. Provider and usage availability varies by platform. See the README for details and source installation.
